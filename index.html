จุดแข็งของพวกเรา

แพรพลอย

  • เรียนรู้เครื่องมือใหม่ได้เร็ว
  • ทำงานเป็นทีม
  • รับฟังความคิดเห็นของผู้อื่น
  • มีความละเอียดในการทำงาน

กัลยกร

  • เรียนรู้เทคโนโลยีใหม่ ๆ
  • สามารถทำงานร่วมกับผู้อื่น
  • สนใจการออกแบบเว็บไซต์
  • มีความรับผิดชอบต่องาน

ทักษะของพวกเรา

HTML

CSS

JavaScript
